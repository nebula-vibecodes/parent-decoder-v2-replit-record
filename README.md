# Parent Decoder v2 — Replit Work Record

> **Status: development record / beta comparison — not the release version**

This repository records the work completed for the new version of Parent Decoder (**v2**) on Replit, compared with the version deployed on Lovable as a public beta test.

## What this version includes

- A newly integrated AI assistant.
- An expanded slang library.
- The related product and implementation work completed in the Replit version.

## Important scope note

This is **not the release repository or release version**. It is a straightforward record of the work that has been done in v2 and how it differs from the Parent Decoder beta currently deployed through Lovable for public testing.

The public Lovable deployment remains the beta reference point. This repository should not be treated as a production release, a promise of feature completeness, or a substitute for a later release-readiness review.

## Safety and editorial boundary

Parent Decoder should provide context and education, not surveillance or certainty about a person’s private behavior. A matched term is not proof of intent or conduct. The AI assistant should preserve that boundary, make uncertainty visible, avoid overconfident interpretations, and direct urgent situations to qualified professional or emergency resources.

## Release disclaimer

Before any release decision, verify the rendered user experience, source attribution, privacy behavior, accessibility, mobile behavior, AI-assistant guardrails, and the expanded slang entries against their editorial sources. No release claim is made by this record alone.
