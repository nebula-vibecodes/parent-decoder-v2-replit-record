---
name: Sensitive editorial release gate
description: Durable policy for publishing sensitive Parent Decoder dictionary language
---

Unreviewed sensitive dictionary entries must remain explicitly prototype-only. A
verified release requires a qualified subject-matter or appropriately scoped
lived-experience reviewer, a named independent source, and a real review date.

**Why:** Reviewer identity, qualification, source provenance, and dates cannot be
honestly invented by an automated build or editorial prototype.

**How to apply:** Preserve the blocked verified-launch status until real review
evidence is recorded. Keep standard dictionary QA green for prototype content,
and use the public-launch validation gate to prevent unsupported reviewed status.
